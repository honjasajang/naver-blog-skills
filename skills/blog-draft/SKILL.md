# 초안 쓰기 — 규격에 맞춰, 결론 먼저, 사람 말투로

## 0. 가게 파일을 먼저 읽는다
`가게`(이름·사이트) · `손님` · `말투`(끝맺음기본·군말·금지어) · `금지` · `검색어`(가족·우리글) · `기준치.글규격`(본문최소·가족덮기최소·제목변형최소·제목최대·문장최대·줄최대·리듬최소·해요섞임최소·물음최대·카드가로세로) · `폴더.초안`.
**기준치가 비어 있으면 쓰지 않는다** — blog-reference-read로 상위 글을 재서 채우는 게 먼저다. 남의 업종 규격으로 쓰면 그 업종 글이 된다.

## 1. 쓰기 전에 손에 있어야 하는 것
1. 검색어와 가족(blog-keyword-pick 결과) — 한 글이 받을 검색어 5~8개.
2. 그 검색어 레퍼런스 읽기 결과(7일 안) — 길이·소제목 수·사진 수·표(글자인가)·끝맺음 분포·첫 줄 꼴·눈에 띄는 것.
3. 글의 **숫자 재료** — 자기 데이터·실측·공식 통계. 지어내지 않는다. 없으면 숫자 없이 쓴다.

## 2. 초안 폴더 만들기
```
node skills/blog-draft/scripts/새초안.mjs "<검색어>" "<폴더이름(영문-슬러그)>"
```
→ `<폴더.초안>/<날짜>-<슬러그>/post.json`(틀) · `cards.html`(가로형 카드 틀, 선택). 글은 **post.json에 직접 쓴다**.

## 3. post.json 쓰는 규칙 (blog-draft-check가 그대로 잰다)
- `title`: 검색어 머리말 + **변형 검색어를 몰아넣는다**(제목변형최소 이상) · 길이는 `제목최대` 이하(휴대폰 두 줄). 상위 1~3위 제목 틀에서 단어를 가져오고, 지어낸 은유는 쓰지 않는다.
- `keyword` · `가족`(머리말 배열) · `tags`(8~12개, 검색어 변형 위주).
- `blocks` 순서: `img`(표지 카드) → `p`(첫 문단) → `h`/`p`/`ul`/`table`/`img` 반복 → (`link` 한 줄, 맨 끝, 선택).
- **첫 세 줄 = 장면 · 질문 · 공감.** 「○○입니다」 인사 뒤 바로 손님 상황을 그리고, 손님이 치는 질문을 그대로 묻고, 한 줄 공감. 교재처럼 정의부터 시작하지 않는다.
- **결론 먼저.** 두 번째 문단에 답을 준다. 근거·숫자는 뒤에.
- **문단 안 줄바꿈(`\n`)은 한두 문장마다.** 상위 글은 줄이 짧다(한 업종 실측 17~20자). 문장 평균 `문장최대` 이하, 줄 평균 `줄최대` 이하.
- **끝맺음**은 `말투.끝맺음기본`(대개 합니다체)에 **해요체를 `해요섞임최소` 문장 이상 섞는다**(「~죠?」「~해 보세요」). 해요 비율 상한은 없다.
- **박자를 흔든다.** 「딱 절반입니다.」 같은 짧은 줄을 섞어 문장 길이 들쭉날쭉(`리듬최소` 이상). 물음표는 `물음최대`/천 자 이하.
- **군말·금지어 0.** `말투.군말`(우리만 반복하는 끝맺음)은 한 번까지, `말투.금지어`는 0. 스스로 깎는 말·가상 사례 해명 문구 금지.
- **반복 칸은 여는 방식을 바꾼다.** 「○○ 사주 특징」 같은 칸이 다섯 번 나오면 다섯 번 다 「○○은 ~입니다」로 열지 않는다 — 장면·질문·숫자·비교·한 줄 결론으로 돌아가며.
- **숫자는 목록이나 표로.** 문장 안에 숫자 셋 이상 나열하지 않는다. 표는 **글자 표**(`table`), **3칸 이하**, 3칸이면 칸 글자 7자·2칸이면 10자 이하(휴대폰 390px).
- **가족 덮기.** 소제목·본문에 가족 검색어의 꼬리말(「○○ 여자」「○○ 뜻」「2027 ○○」)이 실제 문장으로 들어가게. `가족덮기최소` 이상.
- **본문에 우리 가게 이름을 넣지 않는다**(상위 글은 본문에 상호를 안 쓴다). 첫 줄 인사와 끝 링크 한 줄만.
- **링크는 글 맨 끝 한 줄**(`{"t":"link","url":…}`, utm_term은 슬러그). 본문 중간·사진에는 걸지 않는다(「동일 링크 반복」 스팸 기준).
- **카드(사진)**는 `기준치.글규격.카드가로세로`(기본 1080×810 가로형). 정사각형은 휴대폰에서 장당 1.45배를 먹는다. 사진 수·비중은 레퍼런스 분포에 맞춘다. 카드 그림에 가격표·판매 UI를 넣지 않는다.
- 용어는 손님 말로. 전문용어는 괄호 뜻풀이 없이 깔지 않는다 — 레퍼런스 난이도(용어 밀도)에 맞춘다.

## 4. 쓰고 나서
1. `node skills/blog-draft/scripts/미리보기.mjs <초안 폴더>` → `미리보기.html`을 **휴대폰 폭으로** 본다(표 350px·사진 비중).
2. 카드가 있으면 `node skills/blog-draft/scripts/카드캡처.mjs <초안 폴더>` → PNG. 넘치면 찍지 않고 멈춘다.
3. **blog-draft-check를 돌린다.** 걸리면 글을 고친다. 문턱은 안 건드린다.
4. 통과하면 blog-paste.

## 5. 한계
- 글의 품질은 재료(숫자·경험)에서 나온다. 이 skill은 꼴을 맞춰 주지 내용을 만들어 주지 않는다. 경험을 지어내지 않는다.
- 끝맺음·리듬 판정은 정규식이라 「~죠?」는 해요로 센다. 사람이 소리 내어 읽어 보는 것을 대신하지 않는다.
