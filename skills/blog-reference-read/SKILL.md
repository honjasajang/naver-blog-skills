# 레퍼런스 읽기 — 상위 글의 짜임과 말투를 숫자로

베낄 것은 검색어가 아니라 **글의 크기와 한 글이 먹는 범위, 그리고 말투**다. 한 업종 실측(2026-09-28)에서 우리 글은 상위 글의 절반 길이에 한 글이 검색어 0자리였고, 끝맺음은 맞췄는데 문장·줄 길이가 1.5~3배 길어 「말투가 이상해」 소리를 들었다. 이 skill은 그 차이를 **매번** 숫자로 보게 한다.

## 0. 가게 파일을 먼저 읽는다
`.agents/blog-shop.md`의 `가게.블로그ID`(우리 글은 열지 않는다) · `말투.군말` · `기준치`(비어 있으면 이 skill이 채운다) · `폴더.자료`.

## 1. 링크는 사용자가 준다 (검색 긁기 금지)
1. 사용자에게 **휴대폰으로** 네이버에 그 검색어를 치고 **첫 화면**에 보이는 블로그 글 링크를 3~10개 붙여 달라고 한다(통합검색 첫 화면은 블로그 탭과 다르다 — AI 브리핑·인플루언서·동영상이 섞인다). 몇 번째에 있었는지(「AI 브리핑 출처 1번」 「블로그 칸 2번째」)도 적어 달라고 한다.
2. 어느 검색어의 레퍼런스인지 `--검색어 "<검색어>"`로 꼭 적는다 — blog-draft-check가 「7일 안에 그 검색어 레퍼런스를 읽었나」를 이걸로 본다.
3. 우리 블로그 글(가게 파일 블로그ID)은 열지 않는다. 자동 검색·자동완성 긁기는 하지 않는다(네이버 약관).

## 2. 재기
```
node skills/blog-reference-read/scripts/읽기.mjs --검색어 "<검색어>" <링크1> <링크2> …   [--화면 3]
```
글마다: 글자 수·제목 길이·소제목·사진(장·가로세로)·표(칸 수·글자 표인가)·인용·구분선·내 글 링크·태그 수·공감·댓글·올린 날 / 말투 지문: 문장 평균·줄 평균·끝맺음 분포(니다/요/다)·해요 섞임·물음/천 자·리듬(문장 길이 들쭉날쭉)·군말 수 / 첫 다섯 줄·끝 다섯 줄.
결과는 `자료/레퍼런스/읽기-<날짜>.json`과 본문 `.txt`(겹침검사용)에 쌓인다. `--화면 N`이면 상위 N편의 휴대폰 첫 두 화면을 PNG로 찍는다 — **글자 수만 보지 말고 그림을 봐라**(사진 비중·표가 글자인지).

## 3. 분포로 말한다 (최고 1편 금지)
- 항목마다 **중앙값·Q1·Q3·N**. 한 편이 유독 길거나 짧으면 그 편을 지목하되 기준은 분포로.
- 끝맺음은 **비율**로(니다 89%·요 8%…). 해요 섞임은 「몇 문장」으로.
- 표는 「글자 표인가 그림인가」, 「칸 수」(휴대폰은 4칸부터 옆으로 밀린다)를 따로 센다.

## 4. 기준치 제안 (가게 파일 `기준치.글규격` 꼴 그대로)
읽은 분포에서 **문턱은 상위 글 범위의 안쪽**으로 잡는다 — 길이는 중앙값보다 조금 아래(본문최소), 문장·줄 길이는 Q3보다 조금 위(문장최대·줄최대), 제목은 90분위(제목최대). 스크립트가 JSON 블록으로 제안하고, **사람이 확인한 뒤** 가게 파일에 붙인다. 제안마다 `_근거`(N·중앙값·분위수)를 같이 적는다.

## 5. 한계 — 결과에 적는다
- 링크는 사용자가 본 첫 화면 기준이다. 날짜·순위는 그날 그 사람 화면이다.
- 옛 편집기 글(se-main-container 없음)은 짜임을 못 읽는다 → 「못 읽음」.
- 공감·댓글·날짜는 화면에 안 보이면 null. 끝맺음 판정은 정규식이라 「~죠?」류는 해요로 센다.
- 이 숫자는 「그 업종 그 검색어」의 값이다. 다른 업종·검색어에 그대로 쓰지 않는다.

## 6. 출력 꼴 (고정)
```
■ 「<검색어>」 레퍼런스 N편 (읽음 a · 우리 글 건너뜀 b · 못 읽음 c)
  글자 중앙 <x> (Q1~Q3) · 제목 <y>자 · 소제목 <n> · 사진 <n>(가로형 n%) · 표 <n>(글자 표 n)
  말투: 문장 <x>자 · 줄 <y>자 · 니다 <p>% · 해요 <q>문장 · 물음 <r>/천 자 · 리듬 <s> · 군말 <t>
  눈에 띄는 것: <표를 글자로 넣는다 / 첫 줄이 질문으로 연다 / 내 글 링크 n개 …>
■ 기준치 제안 (가게 파일 기준치.글규격에 붙여 넣기 전에 사람이 확인)
  { …JSON… }
■ 못 본 것
```
