# 초안 검사 — 발행 전에 기계가 막는다

「적어두면 또 어긴다」 종류의 실수를 기계로 옮긴 것이다. 한 업종에서 세 편을 다 쓰고 나서야 「수요를 안 쟀다·글이 상위 글의 절반이다·한 글이 검색어를 0자리 먹는다」가 드러났고(2026-09-28), 말투 지적을 세 번 받고(9/30·10/3·10/6) 문장·줄 길이·군말을 숫자로 옮겼으며, 끝맺음·길이가 맞아도 박자가 고르면 기계 티가 나서(10/10) 리듬·해요 섞임·물음을 넣었다. 문턱은 그때그때 상위 글 실측에서 나왔다.

## 0. 가게 파일을 먼저 읽는다
`기준치.글규격`(본문최소·가족덮기최소·제목변형최소·제목최대·문장최대·줄최대·말버릇최대·리듬최소·해요섞임최소·물음최대) · `기준치.자리` · `수요.환산.지수` · `말투.군말` · `말투.금지어` · `폴더.자료`.
**기준치가 비어 있으면 검사하지 않는다** → blog-reference-read로 그 업종 상위 글을 재서 채우라고 한다.

## 1. 초안 꼴 (post.json)
```json
{ "title": "…", "keyword": "젤네일 가격", "가족": ["젤네일"], "tags": ["…"],
  "blocks": [ {"t":"h","x":"소제목"}, {"t":"p","x":"문단. 줄바꿈은 \\n"}, {"t":"ul","items":["…"]},
              {"t":"img","src":"01-cover.png"}, {"t":"table","rows":[["칸","칸"],["…","…"]]} ] }
```
초안 폴더에 카드 PNG(`01-*.png`)가 있으면 전부 `img` 블록으로 본문에 들어가 있어야 한다.

## 2. 실행
```
node skills/blog-draft-check/scripts/검사.mjs <초안 폴더>
```
exit 0 통과 · 1 규격 미달(고쳐라) · 2 잴 자료 없음(기준치·수요·레퍼런스부터).

## 3. 무엇을 막나 (🔴 = 미달이면 막음 · ⚠️ = 알고는 있어라)
| 검사 | 기준(가게 파일) | 왜 |
|---|---|---|
| 🔴 본문 글자 수 | `본문최소` | 상위 글의 절반 길이로는 안 뜬다 |
| 🔴 가족 덮기 | `가족덮기최소` — 그 가족 검색어 중 제목·소제목·본문이 실제로 받는 수 | 한 글이 검색어를 여러 개 먹어야 한다 |
| 🔴 제목 변형 | `제목변형최소` | 1위 제목은 변형을 몰아넣는다 |
| 🔴 제목 길이 | `제목최대` | 휴대폰에서 네 줄 되면 덩어리로 보인다 |
| 🔴 문장·줄 평균 | `문장최대`·`줄최대` | 상위 글은 짧게 끊고 한두 문장마다 줄을 바꾼다 |
| 🔴 군말 | `말버릇최대`, 목록은 `말투.군말` | 우리만 반복하는 끝맺음 |
| 🔴 리듬·해요·물음 | `리듬최소`·`해요섞임최소`·`물음최대` | 박자가 고르면 교재 티 |
| 🔴 금지어 | `말투.금지어` | 스스로 깎는 말·해명 문구 |
| 🔴 표 | 4칸 이상 금지 · 3칸 표 칸 글자 ≤7 · 2칸 ≤10 | 휴대폰 390px 실측 |
| 🔴 카드 누락 | 폴더 PNG ⊂ img 블록 | 만들어 두고 안 넣은 사고 |
| 🔴 레퍼런스 7일 | `자료/레퍼런스/읽기-*.json`에 그 검색어가 8일 안 | 잘된다고 레퍼런스에 소홀해진다 |
| ⚠️ 수요 | `수요.환산.지수` 아래면 경고. 수요 자료 자체가 없으면 경고 | 10위 들어도 하루 2회면 알고 써라 |
| ⚠️ 자리 | `자리.약한자리최소` | 상위 10이 큰 블로그면 못 뚫는다 |
| ⚠️ 태그 수 | 12 초과 | 새 글이 잘 들어가는 블로그는 8~12개였다(근거 약함) |

## 4. 걸리면
문턱을 바꾸지 않는다. 글을 고친다. 문턱이 틀렸다고 생각되면 blog-reference-read로 **다시 재서** 가게 파일을 바꾼다 — 그게 유일한 길이다.
해요 비율은 막지 않고 보여 주기만 한다(한 업종에서 해요 30%대 글이 더 좋다는 판정이 있었다 — 상한을 두지 마라).

## 5. 출력 꼴 (고정)
```
■ <제목>
  검색어 「…」 · 가족 「…」 (표본 안 검색어 n개) · 수요 x · 자리 a/10
  제목 n자 · 본문 n자 · 소제목 n · 가족 덮기 n · 제목 변형 n
  말투 지문 — 문장 x자 · 줄 y자 · 군말 n   (기준: 가게 파일)
  리듬 — 들쭉날쭉 s · 해요 n문장(p%) · 물음 r/천 자
  ⚠️ 알고는 있어라 … / ✗ 규격 미달 … / ✓ 규격 통과
```
