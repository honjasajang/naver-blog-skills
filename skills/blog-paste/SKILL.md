# 붙여넣기 — 발행은 사람이 한다

## 0. 왜 사람이 올리나
한 1인 서비스가 18편을 프로그램으로 에디터에 부어 넣었더니 13편이 검색에 안 들어갔다(2026-09). 네이버 공식 문서에 그대로 걸린다: 게시물 운영정책은 「자동화된 수단(매크로·로봇·스크래퍼 등)을 이용하여 게재한 게시물」을 제한하고, 검색 FAQ는 사람에게 불가능한 타자 속도의 글을 기계 작성으로 본다. 붙여넣기는 사람이 한 번 하는 일이라 괜찮다. **이 skill은 자동 게재 기능을 만들지 않는다** — 요청받아도.

## 1. 전에 끝나 있어야 하는 것
- blog-draft-check **통과**(exit 0). 페이지는 검사 결과를 맨 위에 다시 보여 준다 — 미달이면 빨갛게.
- 카드 PNG가 폴더에 있고 전부 `img` 블록에 들어가 있음.

## 2. 실행
```
node skills/blog-paste/scripts/붙여넣기.mjs <초안 폴더>     → <초안 폴더>/붙여넣기.html
```
페이지를 브라우저로 연다(file://). 위에서부터:
1. **제목 복사** → 에디터 제목.
2. **사진 N장을 글쓰기 화면에 한꺼번에 끌어다 놓는다**(폴더 경로가 적혀 있다). 에디터가 사진을 올리면서 생긴 자리는 그대로 둔다.
3. **본문 전체 복사** → 본문에 붙여 넣는다. 서식(소제목 19 굵게·본문 16·목록·글자 표·문단 사이 빈 줄)째 들어간다. 사진 자리는 노란 줄 「【사진 n】」로 표시되니 그 줄을 지우고 올려 둔 사진을 끌어 놓는다(또는 「사진 n 복사」 → ⌘V).
4. **끝 링크 복사** → 본문 맨 마지막 줄 아래. 링크 카드가 생기면 위의 파란 주소 줄은 지운다.
5. **태그 복사** → 태그 칸.
6. 발행 설정: 공개·검색 허용·주제. 예약 발행 가능.

## 3. 올린 뒤
- 48시간은 고치지 않는다(제목·사진·본문).
- 하루에 올리는 편수는 가게 파일 `배운것`·자기 성적표로 정한다(한 업종에서 하루 두 편 올린 날의 글 6편이 검색에 안 들어간 기록이 있다 — 근거는 약하다).
- 올린 주소를 초안 폴더 `발행.json`에 적고 폴더를 `올린-글/`로 옮긴다. blog-scoreboard가 다음 날부터 센다.

## 4. 하지 않는 것
- 에디터 자동 입력·자동 클릭·예약 자동화. data URI 사진 붙여넣기(에디터가 「허용하지 않는 형식」으로 막는다).
- 본문 중간 링크, 사진에 거는 링크.
- 오늘 올린 글 수를 비공식 엔드포인트로 긁는 것 — 블로그 글 목록을 직접 보라고 안내한다.
