# 설치 안내 — 터미널을 처음 여는 분을 위해

이 안내는 「클로드 코드가 뭔지는 알겠는데 터미널·npm이 무섭다」는 분을 위해 썼습니다. 한국 구매자 조사에서 돈을 안 낸 이유 1위가 「클로드 구독비가 따로 든다」였고, 막히는 자리 1위가 영어가 아니라 **터미널·npm·WSL**이었습니다. 그래서 순서대로 한 번에 하나씩 갑니다.

## 0. 먼저 알아 둘 것
- **Claude Pro 이상**(월 $20~)이 필요합니다. Claude Code는 Pro·Max 플랜에 들어 있습니다. 무료 플랜으로는 안 됩니다.
- 네이버 블로그 계정, 그리고 네이버 **개발자 센터 API 키**(무료, 5분)가 필요합니다. 검색어 고르기와 성적표의 색인·순위에 씁니다.
- 글은 **사람이 올립니다.** 이 도구는 자동으로 네이버에 글을 올리지 않습니다(네이버 운영정책). 대신 붙여 넣기만 하면 되는 페이지를 만들어 줍니다.

## 1. Node.js 설치 (스크립트를 돌리는 엔진)
1. https://nodejs.org 에서 **LTS** 버튼으로 내려받아 설치합니다(맥·윈도 같음).
2. 터미널을 엽니다. 맥은 「터미널」 앱, 윈도는 「PowerShell」.
3. 아래를 붙여 넣고 엔터. 숫자가 나오면 됩니다.
   ```
   node -v
   ```

## 2. Claude Code 설치
```
npm install -g @anthropic-ai/claude-code
claude
```
처음 `claude`를 치면 로그인 창이 열립니다. Pro/Max 계정으로 로그인합니다.

## 3. 이 도구 내려받기
```
git clone https://github.com/honjasajang/naver-blog-skills.git
cd naver-blog-skills
npm install
npx playwright install chromium
```
마지막 줄은 「레퍼런스 읽기」가 상위 글을 열어 보는 데 쓰는 브라우저입니다. 한 번만 하면 됩니다.

## 4. 네이버 API 키 (5분)
1. https://developers.naver.com → 로그인 → **Application → 애플리케이션 등록**.
2. 이름은 아무거나. **사용 API**에 **「검색」**과 **「데이터랩(검색어트렌드)」** 둘을 추가합니다.
3. 환경: 「WEB 설정」에 `http://localhost` 하나 적어 두면 됩니다.
4. 발급된 **Client ID / Client Secret**을 이 폴더의 `.env` 파일에 적습니다(파일이 없으면 새로 만듭니다).
   ```
   NAVER_CLIENT_ID=여기에
   NAVER_CLIENT_SECRET=여기에
   ```
   이 파일은 남에게 보내지 않습니다. 하루 한도는 검색 25,000회 · 데이터랩 1,000회라 개인 블로그엔 충분합니다.

## 5. 우리 가게 파일 만들기
```
cp .agents/blog-shop.example.md .agents/blog-shop.md
```
`.agents/blog-shop.md`를 열어 **1. 가게 · 2. 손님 · 5. 검색어 씨앗 · 블로그 ID** 네 칸만 먼저 채웁니다. 나머지는 skill이 묻거나 채웁니다. 예시는 가상의 네일샵이고, 기준치 숫자는 다른 업종(운세) 실측값이라 **그대로 쓰면 안 됩니다** — 「레퍼런스 읽기」가 여러분 업종 상위 글을 재서 채웁니다.

## 6. Claude Code에 skill 붙이기
```
claude
/plugin marketplace add honjasajang/naver-blog-skills
/plugin install naver-blog-skills
```
설치 뒤 `claude` 안에서 이렇게 말하면 됩니다: **「젤네일 가격으로 블로그 글 하나 쓰자」** → 검색어 고르기 → 레퍼런스 읽기 → 초안 → 검사 → 붙여넣기 페이지 순으로 갑니다.

## 7. 성적표용 크롬 (선택)
조회수는 **로그인한 자기 크롬**으로만 읽습니다(비로그인 브라우저로 자기 글을 열면 조회수가 오염됩니다). 크롬을 「원격 디버깅 포트」와 함께 띄우고 네이버에 로그인해 둡니다.
- 맥: 터미널에
  ```
  open -na "Google Chrome" --args --remote-debugging-port=9222 --user-data-dir="$HOME/naver-blog-skills-chrome"
  ```
- 윈도: 실행(⊞+R)에
  ```
  chrome.exe --remote-debugging-port=9222 --user-data-dir="%USERPROFILE%\naver-blog-skills-chrome"
  ```
그 크롬에서 네이버에 로그인하고 「로그인 상태 유지」를 켭니다. 가게 파일 `폴더.크롬포트`에 `9222`를 적습니다. 이 크롬은 성적표가 통계 화면만 읽고, 검색이나 글 열기는 하지 않습니다. 끌 때는 창을 닫지 말고 크롬을 정상 종료(⌘Q)해야 로그인이 남습니다.

## 8. 막히면
| 증상 | 원인 | 할 일 |
|---|---|---|
| `command not found: node` | Node 설치가 안 됐거나 터미널을 안 껐다 켬 | 1번 다시, 터미널 새로 열기 |
| `NAVER_CLIENT_ID가 없다` | `.env`가 없거나 다른 폴더에서 실행 | `cd naver-blog-skills` 뒤 다시 |
| `가게 파일이 없다` | 5번 안 함 | `cp` 한 줄 |
| `기준치가 비어 있다` | 레퍼런스를 아직 안 읽음 | 「레퍼런스 읽기」부터 |
| `Executable doesn't exist`(Playwright) | 브라우저 미설치 | `npx playwright install chromium` |
| 성적표 「통계 화면이 안 열린다」 | 그 크롬에서 네이버 로그인이 풀림 | 7번 크롬에서 다시 로그인 |
