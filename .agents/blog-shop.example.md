# 우리 가게 파일 — 네이버 블로그 글쓰기 공정의 단일 출처

모든 skill이 **이 파일을 먼저 읽고**, 비어 있는 칸만 묻습니다. 아래는 가상의 1인 네일샵 「손끝」을 예로 채운 것입니다. 자기 가게 값으로 바꿔 쓰세요.
숫자 칸(기준치)은 **업종마다 다시 재는 값**입니다. 예시 기준치는 운세·사주 업종 상위 글을 실측해 나온 값(2026-09~10)이라 다른 업종엔 그대로 맞지 않습니다. 처음엔 비워 두고 `blog-reference-read`가 그 업종 상위 글을 재서 채우게 하는 것이 맞습니다.

## 1. 가게
- 이름: 손끝
- 업종: 1인 네일샵(예약제)
- 팔 것: 젤네일 55,000원 · 케어 30,000원 · 이달의 아트 70,000원
- 사이트: https://example.com/sonkkeut
- 네이버 블로그 ID: sonkkeut_nail

## 2. 손님
- 누가 읽나: 20~30대 여성, 거의 전부 휴대폰
- 뭘 찾나: 「젤네일 가격」「네일 디자인 추천」「손톱 손상 관리」처럼 가격·디자인·관리법

## 3. 말투
- 끝맺음 기본: 합니다체(상위 글과 같음). 해요체를 3문장 이상 섞는다(「~죠?」「~해 보세요」).
- 우리가 자주 쓰는 군말(기계가 막는다): 자기 글에서 반복되는 끝맺음을 적는다 — 예: 읽습니다 · 풉니다 · 셈입니다
- 쓰지 않는 말: 스스로 깎는 말(「물론 전문가는 아니지만」) · 가상 사례 해명 문구 · 전문용어를 뜻풀이 없이 깔기

## 4. 금지
- 본문에 우리 가게 이름을 넣지 않는다(검색 노출 실측 — 상위 글은 가게 이름을 본문에 안 쓴다).
- 결과·시술 사진에 가격표·이벤트 UI를 넣지 않는다.
- 발행은 사람이 한다. 자동 게재 도구를 쓰지 않는다(네이버 게시물 운영정책 「자동화된 수단」).

## 네이버 API 키
`.env`에 둡니다(이 파일에 적지 마세요).
```
NAVER_CLIENT_ID=
NAVER_CLIENT_SECRET=
```
발급: developers.naver.com → 애플리케이션 등록 → 「사용 API」에 **검색**과 **데이터랩(검색어트렌드)** 둘을 추가. 하루 한도: 검색 25,000회 · 데이터랩 1,000회.
