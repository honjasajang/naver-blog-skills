# naver-blog-skills — 혼자사장의 네이버 블로그 글쓰기 공정 (Claude Code용, 작업 중)

만든 사람: **혼자사장**(honjasajang) — 혼자 일하는 사장이 혼자 돌리는 블로그 공정. 유튜브·네이버 블로그·인스타·오픈카톡 모두 같은 이름(2026-10-30 확정).

마케터·1인 사업자가 Claude Code로 네이버 블로그 글을 **고르고 → 상위 글을 읽고 → 규격에 맞춰 쓰고 → 기계로 검사하고 → 사람이 올리는** 공정. 1인 서비스 하나가 두 달 실전에서 다듬은 도구를 범용으로 뺀 것.

- Claude **Pro 이상**이 필요합니다(Claude Code).
- 발행은 사람이 합니다. 자동 게재 도구는 없습니다(네이버 게시물 운영정책).
- 네이버 **공식 API**(검색·데이터랩)만 씁니다. 키는 본인이 발급해 `.env`에.

## 지금 상태 (2026-10-30)
| | 상태 |
|---|---|
| `.agents/blog-shop.example.md` 우리 가게 파일 | 초안(가상 네일샵 예시) |
| `skills/blog-keyword-pick` 검색어 고르기(자리×수요×가족) | 초안 — 공식 API 스크립트 3(dry·실데이터 확인, 실 API는 키 대기), evals 5 |
| `skills/blog-reference-read` 상위 글 짜임·말투 읽기 → 기준치 제안 | 초안 — 사용자가 붙인 링크만 연다(검색 긁기 없음). 공개 글 3편으로 동작 확인, evals 4 |
| `skills/blog-draft-check` 초안 검사(기계가 막는다) | 초안 — 가게 파일 기준치로. 실제 초안 1편에서 원본 도구와 같은 숫자 확인, evals 5 |
| `skills/blog-draft` 초안 쓰기(규격·첫 세 줄·결론 먼저·글자 표·가로 카드) | 초안 — 새초안(틀)·미리보기·카드캡처 스크립트, evals 5 |
| `skills/blog-paste` 붙여넣기 페이지(사람이 발행) | 초안 — 검사 결과·제목·사진·본문(서식째 복사)·끝 링크·태그. 자동 게재 없음, evals 4 |
| `skills/blog-scoreboard` 성적표(우리 접속 거르고·검색 칸만·색인·순위) | 초안 — 통계는 자기 크롬(포트)으로, 색인·순위는 검색 API. 포트·키 없으면 「못 잼」으로 표시 |

설치는 [docs/설치안내.md](docs/설치안내.md) — 터미널을 처음 여는 분 기준으로 Node → Claude Code → 이 도구 → 네이버 API 키 → 가게 파일 → 플러그인 등록 → (선택) 성적표용 크롬 순서.

## 공정 한 바퀴
`blog-keyword-pick`(무엇을 쓸까: 자리×수요×가족) → `blog-reference-read`(상위 글은 어떻게 썼나 → 기준치) → `blog-draft`(규격대로 쓰기) → `blog-draft-check`(기계가 막는다) → `blog-paste`(사람이 올린다) → `blog-scoreboard`(검색에서 온 것만 센다) → 다시 처음.
